01 / Identity

The design DNA

DropElite reads as a cyberpunk command center — gold-on-near-black, glowing accents, monospace data displays. It signals "elite operator tool" to crypto airdrop farmers. Everything else descends from this stance.

// 01
Gold is the brand
A single hero color (#f5c842) carries every important moment: logos, primary CTAs, key numbers, focus rings. Never substitute it for taste.
// 02
Dark by default
Near-black background (#050810) with translucent white surfaces. Light theme exists as a courtesy, not the canonical look.
// 03
Three fonts, three roles
Orbitron for display, Rajdhani for UI text, Share Tech Mono for data and eyebrows. Each has one job — never swap.
// 04
Glow on what matters
Gold elements get a subtle text-shadow / box-shadow glow. Everything else stays quiet. Restraint makes the glow read.

07 / Rules

Five rules to keep it tight

// 01
One gold, one place
If everything is gold, nothing is. Use it on the primary CTA, the key stat, the logo — then stop.
// 02
Mono = data, never prose
Share Tech Mono is for numbers, codes, timestamps, eyebrows. Never use it for paragraphs — it kills readability.
// 03
Uppercase + letter-spacing
Eyebrows and labels always uppercase with ~2-3px letter-spacing. Body text never uppercase.
// 04
Glow only on gold
Box-shadow / text-shadow glows are reserved for gold elements. Don't glow status colors or text — they'll look radioactive.
// 05
Use variables, not hex
Always var(--gold), never #f5c842. Light theme depends on it.
// 06
Two radii max in one view
Don't mix 9px, 12px, 18px, and 20px in one section. Pick a primary card radius and let buttons + pills be the variants.
